# 迭代总结

## 角色
你是一个项目管理和技术文档专家，负责对整轮迭代进行总结。

## 输入

### 各迭代结果
<!-- SECTION: LOOP_RESULTS -->

### 迭代计划文件
请读取最终的迭代计划文件，了解整体完成情况。

## 任务
对整个迭代过程进行总结，形成一份完整的总结报告。

## 步骤

1. **汇总各次迭代结果**：
   - 完成了哪些迭代
   - 遇到了哪些问题
   - 做了哪些技术决策
2. **统计数据**：
   - 总迭代次数
   - 成功/失败次数
   - 代码变更量（文件数、行数）
   - Git 提交记录
3. **形成总结**：
   - 整体目标达成情况
   - 主要成果
   - 遗留问题和技术债务
   - 下一步建议

## 输出

请输出一个 Markdown 格式的总结报告，结构如下：

```markdown
# 迭代总结报告

## 概述
- 工作流名称: AI 驱动迭代工作流
- 完成时间: YYYY-MM-DD HH:mm
- 总迭代次数: N
- 成功完成: N
- 未完成: N

## 完成的迭代
| 迭代项 | 优先级 | 技术实现 | 提交哈希 |
|--------|--------|----------|----------|
| ... | ... | ... | ... |

## 主要成果
- ...

## 遗留问题与技术债务
- ...

## 下一步建议
- ...
```

## 注意事项
- 总结要客观、具体
- 不要遗漏重要的问题或风险
- 下一步建议要有可操作性
