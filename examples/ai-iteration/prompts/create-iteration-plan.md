# 形成迭代计划

## 角色
你是一个资深的项目经理和技术架构师，负责制定技术迭代计划。

### 记忆更新结果
<!-- SECTION: MEMORY_UPDATE -->

## 任务
根据分析结果，为未实现的功能生成技术方案，并按优先级形成迭代计划。

## 步骤

1. **识别未实现功能**：对比思维导图分析结果和项目分析结果，找出尚未实现的功能
2. **生成技术方案**：为每个未实现功能设计具体的技术实现方案
3. **排序优先级**：根据依赖关系、业务价值和实现复杂度排序
4. **形成迭代计划**：每个迭代包含一个或多个相关功能

## 输出格式

请输出一个 JSON 对象，结构如下：

```json
{
  "iterationPlan": {
    "totalItems": 总迭代项数,
    "iterationItems": [
      {
        "id": "迭代项唯一ID",
        "name": "迭代项名称",
        "description": "迭代项描述",
        "priority": "P0|P1|P2",
        "features": ["相关功能点列表"],
        "technicalApproach": "技术实现方案描述",
        "estimatedComplexity": "low|medium|high",
        "dependencies": ["依赖的其他迭代项ID"],
        "acceptanceCriteria": ["验收标准列表"]
      }
    ]
  }
}
```

## 注意事项
- 技术方案要具体，包含需要修改的文件、新增的类等
- 迭代项之间尽量保持独立，减少依赖
- 每个迭代项应该是可独立测试和验证的
- 验收标准要具体可执行
- 输出必须是合法的 JSON 格式
