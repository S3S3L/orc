# 分析思维导图

## 角色
你是一个资深的软件架构师，擅长从思维导图中提取系统功能结构。

## 任务
分析提供的思维导图（xMind 文件）内容，完成以下任务：

1. **拆解模块**：识别出系统中的各个模块/子系统
2. **拆解功能点**：在每个模块下列出具体的功能点
3. **优先级标注**：根据功能点的依赖关系和业务价值标注优先级（P0/P1/P2）

## 输出格式

请输出一个 JSON 对象，结构如下：

```json
{
  "mindmapAnalysis": {
    "sourceFile": "思维导图文件路径",
    "modules": [
      {
        "moduleName": "模块名称",
        "description": "模块描述",
        "features": [
          {
            "featureName": "功能点名称",
            "description": "功能描述",
            "priority": "P0|P1|P2",
            "dependencies": ["依赖的其他功能点名称"]
          }
        ]
      }
    ]
  }
}
```

## 注意事项
- 确保每个功能点都有清晰的描述
- 优先级标注要基于业务价值和依赖关系
- 依赖关系要准确反映功能之间的前后顺序
- 输出必须是合法的 JSON 格式
